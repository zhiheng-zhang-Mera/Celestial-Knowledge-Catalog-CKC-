## 第一次来，从这里开始

只假定能够阅读日常中文、打开网页；不假定会分数、方程、编程、物理、心理学或投资。不能熟练计算时允许使用计算器。不会英文不影响本层入门，外文资源只作补充。

先读 [如何自学和检查自己是否理解](单元/01-如何开始.md)，然后选择一条路线；**不需要先完成全部数学，才能开始心理或经济**。

## 阅读分四层，不再把进阶先修当入门门槛

**直觉入门**：用生活语言说明对象和现象。**基础计算**：能代入简单数字并检查单位。**数学推导**：再补线性代数、微积分、概率分布、动态模型。**研究验证**：最后讨论实验设计、统计推断、论文证据及复现。

学过一页不等于完成整个学科。每页提供例子、练习和参考答案；能独立解释答案为何成立、换一组数或换一个情境仍能处理，才进入下一单元。不通过时返回该页前置，禁止无限加课。
