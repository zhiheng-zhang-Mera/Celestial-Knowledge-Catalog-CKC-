# 进阶补课：按任务补，不把全部课程设为先修

本页是后续需要系统学习的清单，**不是这些专题的完整教材**。已写好的入门解释与原创练习见 28 个自学单元；深入内容通过原分类与外部来源继续查找。

## 数学支线

| 要解决的问题 | 建议补课顺序 | 什么时候再学 |
|---|---|---|
| 会算和读图 | 整数与负数→分数小数→比例百分比→单位→等式→函数→坐标与斜率 | 零基础起点 |
| 三维位置与姿态 | 平面几何→勾股与相似→向量分量→点积→矩阵乘法→角度弧度→旋转表示 | 需要姿态计算时；不是心理经济入门前置 |
| 线性模型 | 方程组→线性组合→矩阵转置与秩→逆和求解条件→最小二乘→特征值与分解 | 拟合、状态估计与模型优化时 |
| 变化与动态 | 函数与图像→平均变化率→极限连续→导数及法则→积分及基本定理→常微分方程→初始条件 | 需要严格动力学与控制推导时 |
| 多变量模型 | 向量矩阵与单变量微积分→偏导→梯度→雅可比→约束优化 | 不是第一次理解反馈的门槛 |
| 频域和交流 | 周期与频率→三角函数→复数运算→复指数→傅里叶表示→采样理论→滤波器设计 | 先看时间序列，之后才推导 |
| 概率统计 | 样本总体→分布与条件概率→期望方差→协方差→抽样分布与标准误→区间与检验→效应量→回归与诊断 | 生活理解可先到描述层，研究再深入 |
| 状态估计 | 线性代数→概率及协方差→状态空间→噪声模型→贝叶斯更新→卡尔曼滤波及假设检验 | 不能只凭“会加权平均”宣称会滤波算法 |

## 工程与计算支线

电脑文件与输入输出→变量类型→条件循环→函数→列表→文件读写→异常调试→测试→算法与数据结构。机器学习之前还要区分训练、验证和测试数据，明确什么叫泛化。

电路符号→电压电流电阻→串并联→电容电感→二极管晶体管→放大与滤波→转换器→时序→微控制器→接口→通信→功耗与故障。电路板、无线电、锂电和人体相关装置涉及另行安全训练，不把安全当附注。

人体测量：基本生理系统→真实量与代理量→传感输出→标定→伪迹→误差与人因。控制：状态机与简单反馈→动态模型→稳定性→估计→规划或学习策略。先定义需要的闭环，再选择是否需要机器学习或强化学习。

## 心理支线

感觉知觉、注意记忆、学习习惯、情绪动机和社会情境是理解社交与自我的基础。需要研究时再补测量、信效度、抽样、实验与相关、混杂、研究伦理、效应量及重复验证。量表得分与临床诊断严格分开；身份探索不是量表考试。

## 经济支线

收支与机会成本→供需与激励→微观宏观→指标口径→货币信用财政→金融工具与估值→信息和情绪→周期景气→风险与验证。政治识读补国家政府政党、制度与执行权、政策生命周期、不同地区制度差异。做量化研究时再加会计现金流、概率统计、时间序列、因果推断与数据版本管理。
