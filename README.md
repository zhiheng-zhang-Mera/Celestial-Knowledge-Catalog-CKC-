## 核心原则

面向人的分类名称、目录、解释和检索入口必须中文；稳定机器编号、协议字段与文件名允许必要编码。正式分类和森林映射由人工批准，Agent 不得自行更改批准状态。

目录是视图，不复制森林的知识原文。一个森林概念可以有多个中文入口；移动目录不改变概念或目录的稳定身份。CKF 原始记录可以多语言，未来检索需要中文查询和中文解释，但本仓不宣称已实现这种能力。

**学科树不等于课程顺序。** 自学先分直觉、计算、推导、研究四层；不把旧目录中的高阶先修关系设为零基础门槛。零基础阅读顺序由自学索引定义，既有分类数据与历史学习关系保持兼容。

需要深入时，进入[263课系统学习阶梯](自学/系统课程阶梯.md)：逐课完成先修自测、分步推导、图解、六道分层题解与综合实践。已有进阶关联另整理为[全量补课次序](自学/进阶全量次序.md)，只在具体概念需要时使用，不要求先读完整个学科树。正文为待复核教学稿，结构检查和代理抽查不代替专业审校或真人学习验证。

## 关联项目与安全

[知识森林](https://github.com/zhiheng-zhang-Mera/Celestial-Knowledge-Forest-CKF-)负责多语言原文、知识与证据；[主程序](https://github.com/zhiheng-zhang-Mera/Celestial-Throne)负责未来运行时入口和授权；[总导航](https://github.com/zhiheng-zhang-Mera/General-Repo-Navigator)仅保留仓库入口。

自学练习只用虚构情境、模拟数据和纸笔计算，不将私人聊天、心理、性别、健康或财务资料放入公开仓库。外部资源只链接，不批量导入原文。遵守 `CEL-POLICY-20261009-v1`；没有新增工作流、运行产品测试、变更 Runner、部署、发布或改动冻结项目。
