# 天穹知识分类目录（CKC）

> **状态：GitHub 初始化文档与分类草案，待人工审定；未实现产品检索服务。** 本仓库维护人类使用的全中文知识导航，不存放知识森林的原文资料。

## 核心原则

- **中文唯一用户导航语言**：所有目录标题、路径、界面标签、中文别名、检索入口与说明必须为中文；允许仅供机器识别的编号、协议字段与 GitHub 文件名。
- **人工分类权威**：正式目录节点、树结构和 CKF 锚点映射，只能经人工批准后发布。Agent 只能提交建议，不能自行改写正式目录。
- **目录是视图而非存储**：一个 CKF 节点可以同时出现在多个中文树状路径；CKF 持有原文、实体与证据，CKC 仅保存路径与经批准的映射。
- **稳定编号**：移动或重命名目录不更换 `目录编号`；废弃节点保留兼容重定向，不重新分配既有编号。
- **多语言检索转交 CKF**：CKC 全中文，CKF 原文不限语言；中文查询必须能召回有权限访问的外文原始资料，默认以中文解释，并保留原文与证据。
