## 从零自学本主题

政治事件影响市场，通常通过预期现金流、贴现率或不确定性。重要的是新信息相对旧预期改变多少，而不是标题是否震撼。已经高度预期的结果也可能价格反应小；相同事件对不同企业影响方向不同。

**学习目标：** 解释事件冲击与情景价值的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
