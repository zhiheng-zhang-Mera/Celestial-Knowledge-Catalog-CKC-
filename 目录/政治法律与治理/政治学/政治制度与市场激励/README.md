## 从零自学本主题

政治制度通过权利、承诺、问责和资源分配影响市场激励。纸面规则相同，执行能力和参与者权力不同，结果也可能不同。制度分析需要说明机制，不能用一个制度标签解释全部经济表现。

**学习目标：** 解释制度与激励的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
