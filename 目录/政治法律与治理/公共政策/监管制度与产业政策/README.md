## 从零自学本主题

监管可针对安全、竞争、信息或外部性，产业政策则可能选择支持某些活动或能力。目标相近的工具也可能有不同副作用：准入限制能保证一定门槛，也可能保护在位企业。评价需同时看问题与替代工具。

**学习目标：** 解释监管目标与执行能力的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
