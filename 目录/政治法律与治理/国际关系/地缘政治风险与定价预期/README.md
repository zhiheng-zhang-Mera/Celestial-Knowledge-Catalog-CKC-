## 从零自学本主题

地缘风险包括冲突等事件及相关不确定性。新闻指数衡量报道中的风险内容，并非直接测得冲突概率。价格反应取决于暴露：能源进口者、出口者和运输企业可能受到不同现金流冲击。

**学习目标：** 解释地缘风险代理与风险溢价；避免指数决定论。
