## 从零自学本主题

比较优势比较放弃另一产品的机会成本，而不是谁在所有产品上更快。贸易可以扩大总可用资源，但收益如何分配还受价格、工资、调整成本和制度影响。跨境资本流动则涉及资产与融资，不等同商品进出口。

**学习目标：** 解释比较优势与跨境资本的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
