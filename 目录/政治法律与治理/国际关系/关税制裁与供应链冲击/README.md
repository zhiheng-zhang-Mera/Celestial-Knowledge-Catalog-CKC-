## 从零自学本主题

关税通常按进口货值或数量征税，制裁可能涉及交易、金融、技术或主体限制，两者机制和法律依据不同。课堂只讨论抽象传导，具体限制必须查现行官方文本，不能从新闻标题推定适用范围。

**学习目标：** 区分关税与数量限制；追踪供应链成本传递。
