## 使用方式

1. 点击一级领域进入其子目录，再按照各页子 README 逐级浏览。
2. 每个分类都有稳定目录编号；相同名称可以在不同路径出现，未来可映射至同一个 CKF 知识节点。
3. 页面中的森林锚点仅为演示候选，**未经映射审核不得当成真实跳转**。
4. Agent 可向 CKF 提议扩展知识；不能擅自修改本目录的正式分类、名称与链接。
5. [完整目录列表](../catalog/目录列表.md) · [CKC 首页](../README.md) · [中文检索规范](../docs/中文检索规范.md)。
