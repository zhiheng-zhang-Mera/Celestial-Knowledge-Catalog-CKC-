## 完全零基础入口

先读[采样与信号](../../../../自学/单元/13-采样与信号.md)。用时间表、取样间隔和三点平均理解基本问题，**不要求先会傅里叶变换**。

## 分层学习

直觉：原始变化、样本、时间戳与缺失。计算：取样频率、简单均值和延迟。推导：再补周期、三角、复数、[傅里叶专题](../傅里叶分析与频域/README.md)，学习带限假设、采样定理和抗混叠滤波。研究：验证噪声、真实事件被平滑掉的风险及实时约束。

原[概率专题](../../../../目录/数学与形式科学/概率论与数理统计/概率与随机变量基础/README.md)和傅里叶前置保留作深入背景，不是所有入门问题的门槛。不能把“平均以后看起来平滑”当作信号更真实。
