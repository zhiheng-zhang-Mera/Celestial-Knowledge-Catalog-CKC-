## 从零自学本主题

职业压力分析关注要求与可用资源是否匹配。倦怠在WHO框架中与长期未妥善处理的工作压力有关，但不能凭疲惫一天就给自己或同事下诊断。工作之外的因素也会影响状态，需要避免单因解释。

**学习目标：** 解释风险因素与组织干预的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
