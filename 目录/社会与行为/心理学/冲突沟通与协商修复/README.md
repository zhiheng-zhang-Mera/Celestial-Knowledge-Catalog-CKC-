## 从零自学本主题

立场是“我要什么方案”，利益是“这个方案满足什么需要”。冲突中双方可能坚持不同立场，却有可兼容的利益。修复既包含承认影响，也包含后续行为，单说抱歉不一定改变导致问题的流程。

**学习目标：** 把立场转换为利益；形成有验收条件的修复约定。
