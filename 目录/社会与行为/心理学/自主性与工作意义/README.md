## 从零自学本主题

自主性指在有边界的任务中拥有一定选择权，不等于没有目标或独自承担所有责任。工作意义可能来自贡献、学习、关系或生活保障，不要求每个岗位都承担人生使命。

**学习目标：** 分辨自主性与放任；把工作意义拆为可讨论因素。
