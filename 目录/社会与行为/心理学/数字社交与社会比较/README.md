## 从零自学本主题

社会比较是借他人信息评价自己。平台内容经过发布者选择与推荐系统筛选，看到的样本不是他人生活的随机切片。观看成功展示后形成落差，既可能与比较方式有关，也可能与当时状态和使用目的有关。

**学习目标：** 解释选择机制与比较基准的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
