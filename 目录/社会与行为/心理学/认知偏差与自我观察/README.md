## 从零自学本主题

认知偏差是某些判断过程中的系统性倾向，不是给别人贴“不理性”的标签。确认偏差表现为更容易寻找、解释或记住支持已有看法的信息。知道偏差名称也不会自动免疫。

**学习目标：** 识别确认偏差与事后解释；建立反证检查。
