## 从零自学本主题

情绪包含体验、身体反应和行动倾向，动机则涉及追求或回避目标的方向与力度。紧张可以推动准备，也可以妨碍专注；不能简单给某情绪贴好坏标签。调节意味着改变与情绪互动的方式，不是要求自己立即没有感受。

**学习目标：** 分开情绪、动机与行动；选择与情境相称的调节步骤。
