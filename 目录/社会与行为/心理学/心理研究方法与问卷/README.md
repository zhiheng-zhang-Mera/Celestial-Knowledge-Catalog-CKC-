## 研究支线再补数学

想分析量表和论文时，沿[统计直觉](../../../../自学/单元/06-统计直觉.md)进入[心理研究与量表](../../../../自学/单元/22-心理研究与量表.md)，再学原[抽样与区间专题](../../../../目录/数学与形式科学/概率论与数理统计/抽样估计与置信区间/README.md)。样本偏差、测量误差、信效度、因果限制与知情同意逐项学习，不把数学符号当可靠性证明。

生活层理解社交、职场和性别，不必须先走完整条研究支线。量表不能替代临床诊断，也不能替个人确定身份。当前无进一步子目录。
