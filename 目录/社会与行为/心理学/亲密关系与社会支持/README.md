## 从零自学本主题

社会支持包括情感理解、实际帮助、信息建议与共同参与。支持是否有用取决于需要和接受方式，帮助越多不一定越好。亲密关系中的回应性，是对方感到被理解和被尊重，不能用随时在线替代。

**学习目标：** 分辨支持类型；提出尊重自主性的支持请求。
