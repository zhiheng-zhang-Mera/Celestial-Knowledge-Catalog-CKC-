## 从零自学本主题

研究伦理不只是签同意书。尊重要求理解与自愿，有利要求认真权衡风险与收益，公正要求合理分配参与负担和收益。涉及敏感资料时，收集最少必要信息通常比收集后再想保护更稳妥。

**学习目标：** 解释同意与再识别的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
