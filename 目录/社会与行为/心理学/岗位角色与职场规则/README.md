## 从零自学本主题

岗位角色回答“对什么结果负责”，职责清单回答“做哪些事”，权限回答“能决定什么”。三者不匹配会产生角色模糊或角色冲突。了解职场规则需要查文本并询问实际流程，不能靠猜测同事行为。

**学习目标：** 澄清岗位责任和权限；区分正式流程与习惯。
