## 从零自学本主题

归因是解释行为原因。看到别人迟到，我们容易想到“不负责”，而解释自己迟到时想到交通。这种不对称值得检查，但不能一见判断失误就给人贴“有偏差”的标签。行为背后既可能有个人倾向，也可能有约束。

**学习目标：** 区分行为事实与归因；检查情境替代解释。
