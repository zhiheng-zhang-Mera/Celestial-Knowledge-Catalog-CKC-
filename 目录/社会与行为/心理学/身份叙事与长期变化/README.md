## 从零自学本主题

身份叙事是把经历组织成“我是谁”的故事。故事提供连续感，也可能删去矛盾证据。一个人可以在保持重要价值的同时改变职业、兴趣和表达，不能把过去的一种选择当成终身定义。

**学习目标：** 解释叙事与纵向比较的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。

**入门补课：** [如何开始](../../../../自学/单元/01-如何开始.md) → [证据与提问](../../../../自学/单元/05-证据与提问.md) → [心理与行为](../../../../自学/单元/17-心理与行为.md) → [自我观察](../../../../自学/单元/20-自我观察.md)。先看正文直觉部分；遇到计算或术语障碍再回退对应单元。原有高阶前置用于后续推导与研究，不作为第一次阅读门槛。
