## 从零自学本主题

人格量表通过一组题目估计某些倾向。常模是用于比较的参考样本，不是人应当达到的标准。不同语言、年龄或场景下同一分数未必等义，解释前需要知道量表适用范围。

**学习目标：** 检查量表用途和常模；解释误差与分数变化。

**入门补课：** [如何开始](../../../../自学/单元/01-如何开始.md) → [证据与提问](../../../../自学/单元/05-证据与提问.md) → [心理与行为](../../../../自学/单元/17-心理与行为.md) → [自我观察](../../../../自学/单元/20-自我观察.md)。先看正文直觉部分；遇到计算或术语障碍再回退对应单元。原有高阶前置用于后续推导与研究，不作为第一次阅读门槛。
