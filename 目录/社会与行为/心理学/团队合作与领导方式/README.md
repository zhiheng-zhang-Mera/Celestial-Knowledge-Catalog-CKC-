## 从零自学本主题

团队合作要求成员的行动能衔接，而非只是所有人努力。共享目标、角色分工和反馈闭环分别解决方向、接口和纠错。领导方式需要放在任务不确定性、成员经验和风险要求中讨论，不能把一种风格奉为万能。

**学习目标：** 解释互依与领导行为的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
