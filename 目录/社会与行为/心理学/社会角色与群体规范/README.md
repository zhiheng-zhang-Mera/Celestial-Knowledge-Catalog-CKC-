## 从零自学本主题

角色是某位置附带的期待，规范是群体对可接受行为的共享判断，正式规则则通常有明确文本和执行程序。“大家都这样做”描述行为频率，“大家认为应该这样做”描述认可，两者不一定相同。

**学习目标：** 解释角色与规范的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
