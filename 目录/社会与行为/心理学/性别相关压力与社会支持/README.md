## 从零自学本主题

压力可能来自歧视、排斥、隐私威胁或服务障碍，而不能把某种身份本身等同于问题。支持需要听取本人目标，关注安全和选择权；公开身份是否合适由本人结合处境决定。

**学习目标：** 解释交叉因素与支持可及性的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
