## 完全零基础入口

先读[力、运动与能量](../../../../自学/单元/11-力运动与能量.md)，其前置从算术、比例单位和图表逐步补齐。**理解基本受力、平均速度和简单匀加速，不必先完成微积分。** 课程层次参考[大学物理课程说明](https://openstax.org/books/college-physics-2e/pages/preface)。

## 分层学习

直觉：位置、位移、速度、加速度、质量和力分别是什么。基础计算：明确单位和假设，计算平均速度和简单受力。推导：学习[变化率](../../../../自学/单元/10-变化率与累计量.md)，再进入原[极限导数专题](../../../../目录/数学与形式科学/分析学/极限导数与变化率/README.md)。研究：检查测量误差、模型限制和实验对照。

旧“极限导数”前置仅适用于深入推导，不再阻挡直觉入门。当前没有继续细分子目录；练习和自查见自学入口。
