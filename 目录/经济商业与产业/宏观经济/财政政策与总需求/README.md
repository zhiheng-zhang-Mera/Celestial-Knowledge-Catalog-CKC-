## 从零自学本主题

财政政策通过支出、税收和转移改变公共资源配置及总需求。政府购买直接计入相应最终支出，转移支付改变居民可支配收入，并不在支付时自动等于新增产出。预算赤字也受经济周期影响，不全是主动政策变化。

**学习目标：** 解释政府购买与乘数的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
