## 从零自学本主题

宏观指标需要统计边界。国内生产总值统计一定时期内的最终生产增加值，不是把每笔交易全加起来。名义量按当期价格计，实际量以价格调整尝试反映数量。人均值又加入人口分母，不能与总量互换。

**学习目标：** 解释流量与实际量的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
