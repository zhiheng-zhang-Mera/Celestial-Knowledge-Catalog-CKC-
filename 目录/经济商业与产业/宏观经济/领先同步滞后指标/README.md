## 从零自学本主题

领先指标通常在目标变化前提供信息，同步指标近似同时变化，滞后指标在目标之后变化。分类依赖目标、时期与数据版本，不是指标永久属性。经济发生时间与数据公布时间还需要分开。

**学习目标：** 解释领先同步滞后；防止发布时点造成偷看未来。
