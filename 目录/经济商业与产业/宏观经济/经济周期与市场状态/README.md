## 从零自学本主题

经济周期是活动的扩张与收缩过程，市场状态则描述资产价格、波动、信用条件等。资产价格反映未来预期，可能早于实体活动变化，也可能因风险溢价变化而背离。不能把股市涨跌直接等同经济好坏。

**学习目标：** 分开经济活动与资产价格；使用多指标描述周期。
