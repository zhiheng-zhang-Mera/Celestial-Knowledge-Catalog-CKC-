## 从零自学本主题

生命周期描述产品或行业从探索、扩张到成熟的结构变化，景气描述相对短期的需求和盈利起伏。成熟行业仍会有技术更新，成长行业也可能短期过剩。不能把示意图当每个行业必经的固定时钟。

**学习目标：** 解释生命周期与景气的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
