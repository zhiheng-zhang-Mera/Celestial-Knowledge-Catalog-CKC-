## 从零自学本主题

行业结构描述参与者数量、替代性、进入退出和上下游关系。先定义市场边界，再谈集中度；同一公司在狭窄产品市场占比很高，在宽市场占比可能很低。市场份额不是利润的自动保证。

**学习目标：** 界定相关市场；分析进入壁垒与议价能力。
