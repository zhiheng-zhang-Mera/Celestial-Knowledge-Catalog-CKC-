## 从零自学本主题

情绪无法直接用一个市场数字完整测量，因此研究使用搜索、文本或交易行为作代理。代理是间接线索，不是情绪本身。指标可能同时受到机器人、平台规则、用户构成和事件关注度影响。

**学习目标：** 解释代理指标与分母标准化的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
