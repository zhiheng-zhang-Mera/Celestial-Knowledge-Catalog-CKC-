## 从零自学本主题

资产配置决定资金分布，风险预算决定愿意让哪些风险贡献多少。等额投入不等于等风险，因为波动和相关性不同。目标、期限和流动性约束需在优化之前定义，否则数学上的最优可能无法执行。

**学习目标：** 区分资金权重与风险贡献；理解约束和风险预算。
