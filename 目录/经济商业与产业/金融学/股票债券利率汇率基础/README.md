## 从零自学本主题

股票收益与企业剩余价值相关，债券支付受合同约定，利率是跨时间交换资金的价格，汇率是一种货币以另一种货币计价的比率。先写报价方向，否则升值贬值容易说反。

**学习目标：** 解释现值与汇率方向的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
