## 从零自学本主题

行为金融研究心理过程与市场制度怎样共同影响决策和价格。偏差可以提出机制假设，但观察到亏损并不能证明存在某种偏差；信息限制、风险补偿和运气也是可能解释。有效研究应说明行为预测在什么条件下不同于替代理论。

**学习目标：** 解释参照点与决策记录的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
