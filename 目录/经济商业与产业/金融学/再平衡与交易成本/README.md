## 从零自学本主题

再平衡是把偏离目标的权重调回既定范围，不等于预测下一阶段赢家。它会改变风险暴露，也可能产生手续费、价差、冲击和税务影响。频繁操作不必然更好，应区分日历规则与偏离阈值规则。

**学习目标：** 解释再平衡与换手与费用的区别和联系；按本课材料独立完成两条分析链并说明适用假设；完成六题与综合实践，保留不确定性和证据边界。
