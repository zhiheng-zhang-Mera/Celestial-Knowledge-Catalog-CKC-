## 从零自学本主题

回测是假装在过去执行规则，关键是当时能知道什么。前视偏差使用尚未公开信息，幸存者偏差只保留今天仍存在对象，选择偏差只展示许多尝试中的赢家。三者都能让历史成绩看起来过好。

**学习目标：** 识别前视幸存者与选择偏差；设计时间顺序验证。

**入门补课：** [如何开始](../../../../自学/单元/01-如何开始.md) → [算术与分数](../../../../自学/单元/02-算术与分数.md) → [比例单位与百分比](../../../../自学/单元/03-比例单位与百分比.md) → [证据与提问](../../../../自学/单元/05-证据与提问.md) → [收支选择与市场](../../../../自学/单元/23-收支选择与市场.md) → [代数与图表](../../../../自学/单元/04-代数与图表.md) → [宏观货币与价格](../../../../自学/单元/24-宏观货币与价格.md) → [心理与行为](../../../../自学/单元/17-心理与行为.md) → [市场情绪与信息](../../../../自学/单元/26-市场情绪与信息.md) → [统计直觉](../../../../自学/单元/06-统计直觉.md) → [周期与轮动](../../../../自学/单元/27-周期与轮动.md) → [风险与验证](../../../../自学/单元/28-风险与验证.md)。先看正文直觉部分；遇到计算或术语障碍再回退对应单元。原有高阶前置用于后续推导与研究，不作为第一次阅读门槛。
