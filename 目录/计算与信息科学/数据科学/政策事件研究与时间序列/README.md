## 从零自学本主题

政策事件研究把特定日期前后变化与基准比较。金融事件研究常看异常收益，政策评估也可看多期处理效应；两者不应混称。时间序列存在趋势、季节和自相关，普通独立样本公式可能低估不确定性。

**学习目标：** 计算差分中的差分与异常变化；检查时间序列假设。
