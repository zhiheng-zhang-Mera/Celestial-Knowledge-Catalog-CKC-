## 从零自学本主题

因果问题问同一对象在接受与不接受某措施时会有什么不同。两个潜在结果无法同时观察，这是因果推断的根本困难。观察到处理组与对照组差异，还可能来自组间原有差异，即混杂。

**学习目标：** 理解潜在结果与反事实；区分混杂和中介。

**入门补课：** [如何开始](../../../../自学/单元/01-如何开始.md) → [证据与提问](../../../../自学/单元/05-证据与提问.md) → [算术与分数](../../../../自学/单元/02-算术与分数.md) → [比例单位与百分比](../../../../自学/单元/03-比例单位与百分比.md) → [统计直觉](../../../../自学/单元/06-统计直觉.md) → [收支选择与市场](../../../../自学/单元/23-收支选择与市场.md) → [代数与图表](../../../../自学/单元/04-代数与图表.md) → [宏观货币与价格](../../../../自学/单元/24-宏观货币与价格.md) → [心理与行为](../../../../自学/单元/17-心理与行为.md) → [市场情绪与信息](../../../../自学/单元/26-市场情绪与信息.md) → [周期与轮动](../../../../自学/单元/27-周期与轮动.md) → [风险与验证](../../../../自学/单元/28-风险与验证.md)。先看正文直觉部分；遇到计算或术语障碍再回退对应单元。原有高阶前置用于后续推导与研究，不作为第一次阅读门槛。
