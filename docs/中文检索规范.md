# 强制中文目录与检索规范

- CKC 的一级到末级目录、菜单、标题、中文关键词、提示、用户可读分类说明全部使用中文。
- 技术 ID、路径及 API 字段可以保持稳定 ASCII 编码，但不得直接作为用户可见的目录名称。
- 中文检索支持同义词、简称、简繁字形匹配；显示名称采用经人工审核的中文规范名称。
- 外语论文或资料不得被复制进 CKC。查询由 CKF 执行跨语言召回，返回中文摘要及可审计的原文出处。
- CKF 无中文释义的记录可以返回“中文名称待核实”，保留原语言名称，不得捏造翻译。
- 用户从任意中文路径进入同一 CKF 节点时，规范森林 ID 不因路径不同而变化。
- 该标准为设计约束，**不是现成的索引、翻译或 UI 实现**。
