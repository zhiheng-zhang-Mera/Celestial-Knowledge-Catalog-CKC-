## 医学示例的多入口

- 医学与健康 → 临床医学 → 内科学 → 内分泌与代谢 → 连续血糖监测
- 工程与技术 → 生物医学工程 → 生物传感器 → 连续血糖监测
- 计算与信息科学 → 边缘智能 → 健康监测应用 → 连续血糖监测

以上多个目录入口可映射同一森林节点，但需人工批准后启用。
