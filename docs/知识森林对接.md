# CKC 到 CKF 的接口契约（草案）

用户点击中文目录 → CKC 返回稳定目录编号和人工批准的森林锚点 → Celestial 服务端完成鉴权 → CKF 对中文查询进行跨语言解析、全文/语义召回与受控图遍历 → 返回中文说明、路径与原始来源。

数据权威：
- CKC：中文目录编号、中文名称、父子关系、导航状态、人工批准锚点映射。
- CKF：森林概念 ID、跨语言别名、图关系、原文、证据与索引。
- Throne：身份、权限、查询上下文、UI、实际可执行 API、运行环境。

约束：多对多映射；不以文本同名替代 ID；CKF 的提议不能替代人工批准；节点合并提供重定向；CKC 入口不授予任何额外森林访问权；权限应在检索、遍历和返回每一步施加。

数据契约字段示例：`catalog_id`、`forest_id`、`query_zh`、`response_language`。这不是已实现的 API。
