# 人工维护与批准流程

1. Agent 或维护者提交分类建议，包含中文名称、候选父节点、检索词、定义、来源、影响的 CKF 映射。
2. 人工检查语义边界、分类重复、术语歧义、父子无环及全部用户可见内容中文化。
3. 经人工批准后才将候选条目变为正式目录；CKC 作为唯一映射写入权威。
4. 既有分类调整须保留稳定 ID；删除需有弃用与重定向登记，不回收旧 ID。
5. 一项森林知识可在多个 CKC 路径出现；批准映射需标明专题对应、学科对应等具体类型。
6. 变更影响用户入口、API、权限或链接时按 Celestial 的跨仓影响清单通知相关仓库。
7. 初始 120 个目录节点已在 2026-10-16 获人工通过，形成正式导航基线。后续改动仍必须逐项人工审定；CKF 的 6 条示例锚点映射尚未批准。

参见 [目录维护与生成规范](目录维护与生成规范.md)，任何中文导航路径变更须同步维护子 README、完整目录索引及兼容指引。
