# 目录结构和子 README 导航规范

## 权威来源

- `catalog/分类目录.json` 是正式分类的机器可读注册表。当前 120 个节点已经人工批准。
- `catalog/目录列表.md` 和 `目录/**/README.md` 是派生的 Markdown 浏览页，更新必须保持与 JSON 的名称、编号、父子关系一致。
- `catalog/森林映射.json` 是另一份独立审核的数据。批准分类不等于批准 CKF 候选映射。

## 文件路径

- 根目录：`目录/README.md`。
- 分类页：`目录/<一级中文名>/<二级中文名>/.../README.md`。
- 中文路径是**人类浏览定位**，唯一身份是文件正文的稳定 `目录编号`；名称调整或移动时须提供旧页面迁移与重定向指引。
- 同名分类允许出现在不同父目录，不允许同一父目录重复相同名称。
- 每个子 README 必须有目录编号、中文面包屑、直接子目录、森林关联状态、返回上级及总目录的链接。

## 审核与权限

1. Agent 可提出**中文**分类建议，但未经人工批准不得变动正式分类。
2. 人工批准后更新权威 JSON，重新生成受影响的目录页、总列表及外部导航链接。
3. 进行树的循环检测、ID 唯一性、子目录唯一性、中文可见性、相对链接可达性检查。
4. CKF 的关系更新、外文原始资料和证据不写入 CKC 的分类页面；森林锚点只有正式人工批准后才能启用跳转。
5. 文档页建立不等于实际 Celestial UI、真实 CKF 查询或正式验收。
