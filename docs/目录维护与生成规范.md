# 中文分类目录维护与生成规范

- `catalog/分类目录.json` 是分类权威：现有 120 个基线分类已批准，143 个新专题待人工复核。
- `catalog/目录列表.md` 与所有 `目录/**/README.md` 是从注册表生成的树状视图，所有中文名称、编号、父子关系、链接必须对应。
- `catalog/学习前置关系.json` 为跨领域的先修学习建议；不可将它当成 CKF 已验证的知识关系。
- `catalog/森林映射.json` 仍为未批准的候选映射，不因目录扩充自动转正。
- 目录显示、检索入口及人类阅读说明均使用中文；机器 ID 和 API 字段可用稳定英文字符。
- 目录移动必须提供兼容重定向，不回收历史稳定 ID；新增分类通过人工复核才视为正式批准。
- 文档生成不表示 Celestial-Throne 已接线、CKF 已索引或产品独立验收已经通过。
