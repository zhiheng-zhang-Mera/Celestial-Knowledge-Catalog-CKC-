# 中文分类目录维护与生成规范

- `catalog/分类目录.json` 是分类权威：现有 120 个基线分类已批准，143 个主题待人工复核；本轮编号、路径和状态保持不变。
- `catalog/目录列表.md` 与 `目录/**/README.md` 是学科浏览视图，名称、编号、父子关系和链接必须对应。
- `catalog/零基础自学索引.json` 是自学顺序权威；28 个学习单元有独立身份，并与既有主题建立衔接。不能为教学次序重排分类 ID。
- `catalog/学习前置关系.json` 及分类中的旧前置字段保留为进阶背景；不再作为完全零基础入门的强制门槛。更深推导和研究依赖按自学规范分别判断。
- 分类视图回答“在哪”，学习视图回答“从哪开始”。教学页优先采用普通中文解释、简单例子与自查题，高阶内容明确标示仍需系统学习。
- `catalog/森林映射.json` 仍为未批准候选；自学单元不等同于森林概念，不能因扩充而自动转正。
- 面向人的目录、提示和检索入口保持中文；必要机器 ID、协议和文件名允许稳定编码。
- 目录移动必须提供兼容重定向，历史 ID 不回收。后续新增仍需人工授权与复核。
- 文档生成不表示 Throne 已接线、CKF 已索引、自动教学已上线或产品独立验收已通过。
